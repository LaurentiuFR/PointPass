# Barlow Condensed

Regular and Bold are sourced from the Google Fonts project:
https://github.com/google/fonts/tree/main/ofl/barlowcondensed

Distributed under the SIL Open Font License included in `OFL.txt`.

The clubhouse UI loads these fonts through Resources. They replace the generic
fallback font in lobby labels while retaining editable, supersampled text.
