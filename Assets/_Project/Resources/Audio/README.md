# Stadium supporter effects

CC0 sounds from SFX Mint. The provider identifies these as AI-generated effects.
The original 44.1 kHz stereo WAV files are included unchanged.

| File | Source and license |
| --- | --- |
| goal_cheer.wav | https://sfxmint.com/sounds/stadium-crowd-02 |
| crowd_disappointed.wav | https://sfxmint.com/sounds/stadium-crowd-07 |
| crowd_applause.wav | https://sfxmint.com/sounds/stadium-crowd-04 |

The goal sting, ball impacts and whistle are synthesized by `FootballSounds`.
Crowd variations use modest pitch and entry-time changes, with quieter opposing
supporters, staggered applause, a controlled fade, and conservative mix headroom.
